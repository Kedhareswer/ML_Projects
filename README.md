## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kedhareswer/ML_Projects.git
   ```

2. **Set up the environment:**
   ```bash
   python -m venv env
   source env/bin/activate  # On Windows: .env\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Choose a project:**
   ```bash
   cd project_name
   jupyter notebook
   ```
